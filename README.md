# Machine Learning & Data Science Portfolio

Learning projects in Machine Learning, Data Science, Computer Vision, NLP and Digital Signal Processing.

## Projects

### Computer Vision

- [Ball Object Detection with RetinaNet and DETR](computer-vision/ball-object-detection)  
  Object detection project for ball localization using RetinaNet-style detector and DETR fine-tuning.  
  **Stack:** `Python` · `PyTorch` · `torchvision` · `OpenCV` · `Matplotlib`

### Natural Language Processing

- [Seq2Seq Machine Translation with Attention](natural-language-processing/seq2seq-machine-translation)  
  Neural machine translation project for Russian-to-English hotel and hostel descriptions using GRU Encoder-Decoder, attention, beam search and BLEU evaluation.  
  **Stack:** `Python` · `PyTorch` · `NLTK` · `subword-nmt` · `Bokeh`

### Digital Signal Processing

- [SSVEP BCI Classification](digital-signal-processing/ssvep-bci-classification)  
  EEG-based SSVEP target classification using FFT, CCA, FBCCA and ICA artifact removal.  
  **Stack:** `Python` · `NumPy` · `SciPy` · `MNE` · `scikit-learn` · `Matplotlib`

## Areas

- **Machine Learning:** model training, evaluation, error analysis
- **Computer Vision:** object detection, semantic segmentation, CNN-based models
- **Natural Language Processing:** seq2seq models, attention, machine translation
- **Digital Signal Processing:** EEG processing, frequency-domain analysis, BCI classification
- **Data Science:** data preprocessing, visualization, metrics and experiment analysis
